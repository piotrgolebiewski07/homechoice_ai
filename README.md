# HomeChoice AI

A web application for analyzing and comparing apartment listings in Poland. It helps users evaluate prices, explore housing-market trends, and support purchase decisions using data analysis and AI models.

## Current features

 - Apartment model
 - Django admin panel
 - Apartment list view
 - Sample apartment fixture

## Run locally

1. Create and activate a virtual environment.
2. Install Django: `pip install Django`
3. Apply migrations: `python manage.py migrate`
4. Load sample apartment data: `python manage.py loaddata apartments/sample_apartments`
5. Start the development server: `python manage.py runserver`
